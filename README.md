# CV — Yauheni Horbach

Personal CV / portfolio site. React + Vite + TypeScript, with a three.js terrain built from GitHub contributions.

**Live:** [cv.horbachzhenja.workers.dev](https://cv.horbachzhenja.workers.dev/)

## Features

- Dark / light theme, cool blue palette
- i18n — EN / PL / RU / UA / BY
- 3D GitHub contribution terrain (three.js)
- Custom cursor, scroll-driven animations

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
```
